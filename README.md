## 自動更新  
> **定期自動彙整資料，無需手動處理。**

- 每日半夜 (JST)
- 每週三、四下午 (JST)

若最新內容剛上線，這的資料尚未更新，你就想查看的話，可切換成RAW模式，將會在本地直接從官方來源抓取必要檔案然後處理即時資料。  
圖片也同樣會自動更新，雖說該工作並非在這處理就是了。以及，圖片必須等排程更新完成後才能夠顯示，目前的功能不支援在本地從資源檔案中提取出圖片。

# Evertale Encyclopedia

[https://evertale.qzz.io/](https://evertale.qzz.io/)

## Multi-language
> **Supports 9 in-game, localized languages.**

- English
- 日本語
- 繁體中文
- 简体中文
- Français
- Deutsch
- Italiano
- 한국어
- Español
 
Information text is taken from each respective localization file. When the corresponding text is absent, English will be used as the fallback. If neither exists, it just returns empty text.  
For the website interface text, I try to follow the in-game terminology. The rest was translated with the help of AI, but I'm unable to judge whether it's accurate.


## Auto-update
> **Data is automatically compiled on a regular basis, without requiring any manual work.**

- Every day at midnight (JST) 
- Every Wednesday and Thursday afternoon (JST) 

If the latest content has just been released and you'd like to view it before the data here is updated, you can switch to RAW Mode to directly fetch needed files from the official source and process the real-time data locally.  
Images are also updated automatically, although this task is handled elsewhere. Furthermore, images are only available for display once the scheduled update has completed, as the current features don't support locally extracting images from asset files.
